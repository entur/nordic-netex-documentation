# Separation of Concerns

> [!NOTE]
> This guide is under development.

## Purpose

This guide will explain the principle of **Separation of Concerns** as applied to NeTEx data modelling — how to partition data across frames, files, and delivery structures for maintainability and clarity.

## Topics (planned)

- Frame-level separation (ResourceFrame vs ServiceFrame vs TimetableFrame)
- File-level separation (line file vs shared data file)
- Temporal separation (planning vs operational data)
- Organisational separation (authority vs operator scope)
